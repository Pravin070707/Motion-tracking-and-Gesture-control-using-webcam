OPERATIONS ----
MOUSE control can be done by 8th pos (index finger tip)
MOUSE click operation can be done by 4 & 8th pos (thumb tip & index finger tip)
VOLUME control can be done by 4 & 12th pos (thumb tip & middle finger tip)
SCREEN SHOT can be done by 4 & 16th pos (thump tip & ring finger tip)
SCROLL Function can be done by 4 & 20th pos (thumb tip & pinky tip)
